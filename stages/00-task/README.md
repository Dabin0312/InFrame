# 0단계 · ObjectNav 과제와 성공 판정

시설 담당자가 “소화기를 확인해 달라”고 요청한다. 로봇은 지정한 종류의 물체를 찾아 이동하고, 담당자가 그 물체를 알아볼 수 있는 영상을 남긴 뒤 스스로 멈춘다. 이 명세는 2026년 11월 9일 개정 과제계획서 6.1절의 평가 기준을 따른다.

## 하나의 주행

출발 위치·방향, 장면 ID와 목표 종류를 고정한다. 학생 정책은 전방 RGB, 목표명과 최근 관측·행동 이력으로 전진 속도, 회전 속도와 STOP을 출력한다. 지도와 목표 좌표는 교사 시범과 평가에 사용한다. 제어 주기는 0.25초, 전진 속도 범위는 0~0.4 m/s, 회전 속도 범위는 −1~1 rad/s다.

| 확인 순서 | 판정과 기록 |
| --- | --- |
| 1. 종료 | 로봇이 STOP을 선택했는지 기록한다. 제한 시간 150초 또는 누적 충돌 3회에 이르면 실패로 종료한다. |
| 2. 접근 | STOP 위치에서 목표 종류의 각 객체가 보이는 **사전 등록 관측 지점**까지 최단 주행 거리를 구한다. 0.8 m 이하인 관측 지점에 대응하는 객체 ID를 모두 기록한다. |
| 3. 마지막 영상 | 두 판독자가 모델명·요청 목표·경로를 가린 마지막 RGB에서 알아본 물체의 종류와 위치를 표시한다. 현장 목록과 지도 투영으로 실제 객체 ID를 대조한다. 이견은 제3자가 판독하고, 식별할 수 없으면 가시성 실패로 기록한다. |
| 4. 성공 | **STOP을 선택했고, 접근 조건을 충족한 ID와 마지막 영상에서 식별한 ID가 하나 이상 일치하면 성공**이다. |

예를 들어 소화기 A의 관측 지점에서 0.4 m 떨어져 멈췄어도 마지막 사진에 소화기 B만 찍히면 실패다. 같은 자리에서 A가 식별되는 사진을 남기면 성공이다. 작업실 시연에서 보고한 0.75 m는 소화기 **중심까지의 수평 거리**이며, 본시험에는 2행의 관측 지점까지 주행 거리를 사용한다.

## 기록 및 본시험 계획

- 에피소드에 장면·시작 자세·목표 종류·분할을 저장한다. 각 스텝에는 시각·RGB·행동·충돌을, 종료 시에는 종료 사유·최단 거리·실제 이동 거리·근접 객체 ID·마지막 영상의 객체 ID·성공 여부를 남긴다.
- 출발 구역을 먼저 나눠 학습 300회, 검증 60회, 시험 60회를 구성한다. 시험은 미학습 출발 자세 20개 × 소화기·의자·쓰레기통 3종이다. 단일 프레임 정책과 최근 네 스텝 이력을 쓰는 정책을 같은 60개 조건에서 각각 평가한다.
- **목표**는 점검 성공 42/60 이상, 점검 성공 기준 SPL 0.50 이상이다. 실패는 0점이며 성공 시 출발점에서 해당 종류의 가장 가까운 유효 관측 지점까지의 최단 거리를 최단 거리와 실제 이동 거리 중 큰 값으로 나눈다. 60회 평균을 보고한다.
- 실제 복도는 통과 가능한 구간 3곳과 차단 구간 3곳에서 실측 기준과 가상 로봇 판정을 대조한다. 두 집단 모두 3/3 일치가 목표다. 정책과 현장 평가 수치는 촬영 후 측정한다.
